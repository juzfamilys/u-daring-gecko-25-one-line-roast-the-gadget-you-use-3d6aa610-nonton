A make.fun bounty entry for **@nonton**: one original line roasting a gadget (well, an app) I use every day.

> "My fitness app congratulated me for walking to the fridge, then asked me to upgrade to premium."

## Run it

```sh
python3 main.py
```

This writes the roast to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`). Pure Python stdlib — no dependencies.
